Hosting

Die App liegt bei GitHub Pages (GitHub Inc., USA). Beim Aufruf verarbeitet GitHub technisch nötige Daten wie deine IP-Adresse, um die Seite auszuliefern und vor Missbrauch zu schützen. Siehe GitHub-Datenschutzerklärung.

Fotos und Töne

Tierfotos und Tonaufnahmen werden direkt von Wikipedia / Wikimedia Commons (Wikimedia Foundation, USA) geladen. Dabei erhält Wikimedia deine IP-Adresse. Siehe Wikimedia-Datenschutzrichtlinie.

Schriften liegen auf demselben Server wie die App – es werden keine Daten an Google Fonts übertragen.

Speicher auf deinem Gerät

Fortschritt, Abzeichen, Rekorde und Einstellungen speichert die App im lokalen Speicher deines Browsers (localStorage). Diese Daten verlassen dein Gerät nicht. Du kannst sie jederzeit über die Browser-Einstellungen löschen.

Profile

Profile (Name, Bild, Spielstand) werden nur auf deinem Gerät gespeichert. Es gibt keine Anmeldung und keinen Server, an den sie übertragen werden. Ein Profil löschst du unter „Profile verwalten“.

Deine Rechte

Du hast das Recht auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung, Datenübertragbarkeit und Widerruf deiner Einwilligung. Du kannst dich außerdem bei einer Datenschutz-Aufsichtsbehörde beschweren.

Fehler melden

Die Melde-Funktion öffnet eine vorausgefüllte Seite auf GitHub. Gesendet wird erst, wenn du dort selbst auf „Create“ tippst; die Meldung ist dann öffentlich sichtbar.
